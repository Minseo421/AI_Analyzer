## Identifier and version policy

Keep a descriptive ID stable when linking the same research artifact from different reports. Store file paths, source versions and checksums separately; a change in report layout does not rename an analysis. Do not silently reuse an existing ID for a different sample or measurement. Preserve historical versions/hashes and record any future replacement. An analysis ID identifies a numerical evidence path, not a universal visual artifact; two students may present it differently or omit it.
