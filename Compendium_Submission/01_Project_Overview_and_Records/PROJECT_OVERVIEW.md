# Project 78 — study overview

**Title:** AI-Use Disclosure Governance and Contributor Compliance in Open-Source Software  
**Researchers:** Minseo Kim and Anna Chibel  
**Supervisor:** Dr. Kelly Blincoe, University of Auckland  
**Study:** 38 purposively selected OSS repositories with AI-related governance policies, 41,338 GitHub PRs closed during the May–September 2026 study window.

The study combines manual repository-level policy analysis, a Java GitHub PR collector and rule-based AI disclosure detector, a manually reviewed validation sample, and repository-level rank analysis of visibility versus observed disclosure rates.

**Main findings:** 11,598 of 41,338 PRs (28.06%) had detected AI-related disclosures; 22 repositories explicitly required AI disclosures in PRs; mean repository disclosure rates were 12.02%, 21.53%, and 51.24% for visibility Levels 1–3 respectively; Spearman's rho = 0.6181 at n = 38.

**Interpretation:** These are observed text disclosures, *not* a directly verified compliance rate. The association cannot establish a causal effect of policy visibility.
