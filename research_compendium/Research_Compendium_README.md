# Research compendium

**Project:** AI-use disclosure governance in open-source software  
**Researchers:** Anna Chibel and Minseo Kim  
**Supervisor:** Dr. Kelly Blincoe, University of Auckland

This compendium contains the data, coding records, validation evidence and documentation supporting the research project. The table below describes the contents of each directory within `research_compendium/`.

| Directory | Contents |
| --- | --- |
| [`irr/`](irr/README.md) | Independent researcher labels and consensus records for the initial 150-PR inter-rater reliability assessment. |
| [`detector_validation/`](detector_validation/README.md) | Historical 350-PR validation and subsequent 708-PR evaluation. |
| [`full_repo_analysis/`](full_repo_analysis/README.md) | Full repository-level PR analysis, summary data and report figures. |
| [`governance_coding/`](governance_coding/README.md) | Manual policy coding sheet, coding definitions and procedure. |
| [`reproducibility/`](reproducibility/README.md) | Research workflow, reproduction instructions and methodological limitations. |
| [`reports/`](reports/) | Final reports, meeting record and reference poster. |

Each directory contains its supporting materials; where applicable, its README explains the files and procedures in more detail.
